# ApexFinance Pro Manual Portfolio & Rebalancing Suite

A fully offline-ready React, Vite, and Tailwind CSS stock tracking, dividend, and portfolio rebalancing suite.

## Pro Features

* **Manual Price Entry & Inline Editing**: Update asset prices instantly following market checks.
* **Sector Breakdown & Dashboards**: Visual allocation charts across categories like Tech, Crypto, and ETFs.
* **Dividend & Yield Tracker**: Projected annual passive income calculation.
* **Investment Journal / Notes**: Record strategies and theses per holding.
* **Target Allocation & Rebalancing Calculator**: Define target weights to generate precise buy and sell recommendations.
* **Transaction History Audit Trail**: Chronological ledger for execution prices and trade costs.
* **Multi-Currency & Backup/Restore**: Support for USD, EUR, GBP, CAD, and JPY with JSON/CSV backup tools.
